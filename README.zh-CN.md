## 方法概述

SAR 具备全天时、全天候的海上监视能力，但微小舰船在复杂场景中依然难以检测。困难不仅来自**尺度**：经过多级
下采样后，一艘小目标可能只剩极少数有效响应，而斑点噪声、海岸线、港口与人造结构会产生同样强的散射响应。
此时实例级特征本身已不可靠，继续加强单个目标的特征表达收益有限。

**QG-ShipDet 将 SAR 微小舰船检测重新表述为「关系正则化的表示学习」。** 它不要求单个实例更具判别力，而是对
*实例之间的关系结构*施加监督：舰船之间保持一致，舰船与强散射难例杂波之间保持可分。该监督由一个面向 SAR 的
**量子关系教师**提供——将每个候选目标编码为量子态，利用**数据重上传与中间纠缠**构建舰船—舰船、舰船—难例
杂波的保真度关系，并以**尺度、难度、置信度三重加权**的方式蒸馏到经典检测器。

量子分支仅在**训练阶段**存在，优化结束后即被移除，因此部署模型的推理拓扑、参数量与 FLOPs 与基线完全一致。

## 主要特点

- **面向微小目标的新建模思路**：用成对的结构化监督弥补微弱的实例证据，而不是依赖更重的骨干网络。
- **SAR 先验引导的量子关系教师**：SPQSE 将多尺度语义、局部散射统计与几何属性映射为目标级量子态；TS-QRG 将
  其转化为与实例相关、经典学生网络难以自行表达的保真度关系。
- **增益落在关键之处**：提升集中于微小目标与杂波抑制——`AP_T` 提升 6.09 / 7.64 个百分点，同时每幅图像的
  杂波虚警下降约 34% / 43%。
- **推理零额外开销**：训练后移除量子分支、关系损失与特征钩子，推理代价与基线检测器完全相同。
- **面向机理的验证**：在相同检测器与配对采样协议下，对比经典关系直接监督、协议对齐的经典教师与量子教师，
  从而区分“关系学习本身”与“量子引导教师”的贡献。

## 方法

### 1. SPQSE：SAR 先验引导的量子态编码

对每个候选实例（真值舰船与同图在线挖掘的强散射难例杂波），在各检测尺度 `ℓ = 1…L` 上采样 `M×M` 的 ROI，
通过非参数自适应聚合将局部均值 `μ` 与标准差 `σ` 压缩为语义 token `s`。七维先验 `p` 补充局部散射与几何
信息：局部均值响应、响应离散度、梯度幅值、归一化方向、目标面积对数、长宽比对数以及归一化的中心—背景对比度。

联合特征 `x = LN([s ‖ p])` 驱动**两个**轻量映射，分别给出幅值型（`R_Y`）与相位型（`R_Z`）旋转角，实现
语义—先验的协同编码而非显式信息解耦：

```text
|ψ_i⟩ = ⊗_q [ R_Z(φ_iq) R_Y(θ_iq) |0⟩ ],   θ ∈ [0, π],  φ ∈ [−π, π]
```

两个编码态的保真度同时取决于 `R_Y` 角与相对 `R_Z` 相位，因此所诱导的关系几何严格强于单轴角度编码；当相位差
全部为零时退化为仅 `R_Y` 的核。两个旋转均为酉变换，编码态天然保持归一化。

### 2. TS-QRG：微小舰船尺度感知的量子关系引导

正样本对（舰船—舰船）约束类内一致性，负样本对（舰船—强散射杂波）约束可分性。难例杂波在线从高散射背景区域
挖掘（尺度匹配、与所有舰船框 IoU < 0.1、按局部归一化散射响应取前 5），正负样本按 1:1 采样，且不显式监督
杂波—杂波关系。

由于**共享的末端酉操作不改变任何内积**，TS-QRG 采用**实例相关的数据重上传**与**中间纠缠**交错的方式，使最终
保真度 `Q(u,v) = |⟨ψ_u|ψ_v⟩|² ∈ [0,1]` 真正与实例相关。教师网络以舰船—舰船、舰船—杂波成对间隔损失进行训练。

经典学生网络由多尺度 ROI 特征构建融合表示，并以归一化余弦相似度给出自身的关系 `C`。蒸馏权重由三部分构成：

| 权重 | 作用 |
|---|---|
| `w_scale` | 强化包含更小目标的样本对 |
| `w_hard` | 强化学生当前仍难以处理的关系（带 stop-gradient，避免通过调整权重本身降低损失） |
| `w_conf` | 抑制与已知样本对语义不一致的教师监督 |

融合关系与各尺度关系使用同一套权重归一化联合蒸馏，并采用 Huber 惩罚，使有效样本对数量变化不会直接改变蒸馏强度。

### 3. 稳定联合优化与纯经典部署

受控梯度桥限制辅助分支对检测器骨干的扰动幅度；由 EMA 教师关系准确率驱动的成熟度门控（τ₀ = 0.60、τ₁ = 0.75）
与时间调度共同控制蒸馏的开启、爬升与后段衰减。检测损失、教师损失与加权关系蒸馏损失联合优化：

```text
L_total = L_det + λ_T · L_T + s(t) · r_T · λ_QRG · L_QRG
```

推理阶段移除辅助分支、关系损失与特征钩子，**部署模型就是一个纯经典检测器**，参数量与 FLOPs 与基线完全一致。

## 实验结果

### 数据集与评测协议

实验使用 **HRSID**（5,604 幅 / 16,951 艘）与 **SSDD**（1,160 幅 / 2,456 艘）。参照 COCO 面积划分原则，将
标注框面积 `A = w·h < 32² pixels²` 的目标定义为**微小舰船**（HRSID 占 54.5%，SSDD 占 62.7%）。整体性能用
`mAP50`、`mAP50:95` 衡量，微小目标性能用该子集上的 `AP_T`、`AR_T` 衡量，杂波鲁棒性用目标召回
`R = 0.90` 工作点处的 `FPPI_clutter` 衡量。主要对比与关键消融在三个独立随机种子下取均值 ± 标准差，实验环境为
Ubuntu 20.04、Python 3.8、PyTorch、CUDA 11.8 与单张 RTX 3090。

### 消融：量子态编码（SPQSE，HRSID）

| 编码方式 | 多尺度语义 | SAR 先验 | R_Y | R_Z | mAP50:95 ↑ | AP_T ↑ | FPPI_clutter ↓ |
|---|---|---|---|---|---|---|---|
| 经典投影 | ✓ | × | × | × | 61.22 | 51.73 | 0.371 |
| 通用 `R_Y` | ✓ | × | ✓ | × | 61.63 | 52.65 | 0.346 |
| 通用 `R_Y` + `R_Z` | ✓ | × | ✓ | ✓ | 61.94 | 53.31 | 0.329 |
| 去掉相位的 SPQSE | ✓ | ✓ | ✓ | × | 62.38 | 54.38 | 0.303 |
| **SPQSE（完整）** | ✓ | ✓ | ✓ | ✓ | **63.09** | **56.49** | **0.267** |

SAR 先验与相位自由度带来**相互独立**的收益：相比去掉相位的同一编码，完整 SPQSE 的 `mAP50:95` 提升 0.71、
`AP_T` 提升 2.11 个百分点，杂波 FPPI 由 0.303 降至 0.267。

### 消融：关系引导（TS-QRG，HRSID）

| 变体 | 量子关系 | 难例关系建模 | 可靠性控制 | mAP50:95 ↑ | AP_T ↑ | FPPI_clutter ↓ |
|---|---|---|---|---|---|---|
| 基线（无关系引导） | × | × | × | 60.67 | 50.40 | 0.404 |
| + 量子教师 | ✓ | × | × | 61.41 | 52.18 | 0.353 |
| + 难例关系建模 | ✓ | ✓ | × | 62.58 | 55.61 | 0.283 |
| 经典教师（协议对齐对照） | × | ✓ | ✓ | 62.67 | 55.48 | 0.287 |
| **TS-QRG（完整）** | ✓ | ✓ | ✓ | **63.09** | **56.49** | **0.267** |

### 机理对照实验

两组对照实验分别回答“增益从何而来”。量子线路对照通过关系间隙 `ΔQ` 分离数据重上传与纠缠的作用；教师对照则
使用输入与蒸馏协议完全一致的两层 MLP 教师，将“量子引导教师”的贡献与“通用关系学习”区分开。

| 类别 | 设置 | ΔQ / ΔC | mAP50:95 ↑ | AP_T ↑ | FPPI_clutter ↓ |
|---|---|---|---|---|---|
| 线路 | 无数据重上传 | 0.40 | 62.08 | 53.70 | 0.326 |
| 线路 | 重上传，无纠缠 | 0.47 | 62.63 | 55.08 | 0.296 |
| 线路 | **重上传 + 纠缠** | **0.59** | **63.09** | **56.49** | **0.267** |
| 教师 | 基线（无关系监督） | 0.16 | 60.67 | 50.40 | 0.404 |
| 教师 | 经典关系直接监督 | 0.27 | 61.92 | 53.05 | 0.346 |
| 教师 | 协议对齐的经典教师 | 0.39 | 62.67 | 55.48 | 0.287 |
| 教师 | **TS-QRG（完整）** | **0.45** | **63.09** | **56.49** | **0.267** |

增益的主要来源是关系学习本身（仅经典关系直接监督即带来 2.65 个 `AP_T` 点）；将协议对齐的经典教师替换为量子
引导教师后，再获得 1.01 个 `AP_T` 点与 0.020 的 FPPI 下降。我们在论文中将这一增量表述为**该任务场景下量子
引导关系几何的证据，而非泛化的量子优势主张**。

在关系空间中可以更直接地观察到同一过程：`ΔQ` 由仅 `R_Y` 编码的 0.26 提升到完整 SPQSE 的 0.39、TS-QRG 的
0.59，而学生的 `ΔC` 在蒸馏后由 0.16 升至 0.45——关系间隙先由教师形成，再迁移到经典检测器。

### 增益随目标尺度、场景的变化

将微小目标按等效框尺寸 `√(wh)` 分组后，相对基线的 `AP` 提升分别为：低于 12 像素约 **+10.0 点**，12–20 像素约 **+6.2 点**，20–32 像素约 **+4.0 点**。实例证据越弱，关系约束的作用越强。

![按目标尺度的增益](assets/qgshipdet-size-gains.svg)

场景维度的结论一致：在 HRSID 上，近岸场景 `AP_T` 提升 **+6.83 点**、远海场景提升 **+5.88 点**，杂波 FPPI 分别
下降 0.225 与 0.117——当舰船与海岸线、人造散射共存时收益更大，同时在开阔水域依然稳定有效。特征响应可视化也
显示，响应更集中于舰船，海岸线等高散射区域上的非目标激活被明显抑制。
